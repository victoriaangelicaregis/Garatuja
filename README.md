# Garatuja

Meu garatujas tava no meu bloco de notas do celular, por isso adicionei no github na aula do dia 28/04.

- 502 = servidor não tá rodando, sobe com `bun --watch run server.ts`
- 409 Conflict = checar se descrição já existe antes de atualizar, usando `findItemByDescription`
- Sempre reiniciar o servidor após mudar o código (ou usar `--watch`)
- Git numa linha: `git add . && git commit -m "msg" && git push`
- Terminal sempre pelo VS Code (`Ctrl + \``), não pelo Posting
- bun install → instala dependências e recria o bun.lock
- @types/bun → definições de tipo para o Bun reconhecer Bun.file(), Bun.write() etc

A única linha que eu realmente achei útil do garatuja foi a do git numa linha que reviso sempre.
